# Simulation study (Section 5)

This folder reproduces every panel of the simulation study reported in Section 5 of
*Zhao, Kolar, Lv — "SMART: A Spectral Transfer Approach to Multi-Task Learning",
arXiv preprint [arXiv:2604.20161](https://arxiv.org/abs/2604.20161) (2026).*
Everything in `result/`, `fig/`, and `logs/` is generated by the scripts here; none of
that is tracked in git.

## 1. Environment

From the repository root:

```bash
python -m venv .venv
source .venv/bin/activate          # on Windows: .venv\Scripts\activate
pip install -e ./smart
pip install -r requirements.txt
```

For the baselines implemented in R, install the R packages listed in the top-level
`R_packages.txt` (`rrpack`, `jsonlite`).

## 2. Random seeds

All 100 Monte-Carlo repetitions are driven by a fixed seed vector
[`data/random_seeds/experiment_seeds.csv`](data/random_seeds/experiment_seeds.csv).
The file is checked into the repo so the experiments are bit-identical across
machines; every `run_*.py` / `run_*.R` driver reads the seed for a given
`rd_seed_id` directly from this CSV.

## 3. Experiment design

Three problem sizes ("models") and four sub-experiments are produced. Each run is
indexed by `(model_id, exp_id, rd_seed_id)`.

| Arg | Values | Meaning |
|---|---|---|
| `model_id` | 0, 1, 2 | Model-I (p=100, q=50), Model-II (p=150, q=100), Model-III (p=300, q=200) |
| `exp_id`   | 0, 1, 2, 3 | `exp1` vary n, `exp2` vary intrinsic rank r, `exp3` vary source rank r_s, `exp4` vary source noise σ0 |
| `rd_seed_id` | 0..99 | Which random seed from `experiment_seeds.csv` to use |

All scripts are designed to be launched once per `(model_id, exp_id, rd_seed_id)` triple
and to write one result file per run into `result/<model>/<exp>/`.

## 4. Running baselines (R)

Four classical reduced-rank regression baselines are run from R. Each produces
`<METHOD>_result_<model>_<exp>_<var>_rd_seed_id=<k>.json`:

```bash
Rscript run_RRR.R    <model_id> <exp_id> <rd_seed_id>
Rscript run_SRRR.R   <model_id> <exp_id> <rd_seed_id>
Rscript run_RSSVD.R  <model_id> <exp_id> <rd_seed_id>
Rscript run_SOFAR.R  <model_id> <exp_id> <rd_seed_id>
```

For instance, the first RRR run with default arguments is

```bash
Rscript run_RRR.R 0 0 0
```

## 5. Running SMART (Python)

`run_SMART.py` runs SMART with the structural ranks `(r_u, r_v)` known (fixed), mirroring
the "oracle" curve in the paper. `run_SMARTCV.py` performs the full selection pipeline
(intrinsic rank via RSC, structural ranks via cross-validation, λ via BIC with Optuna),
matching the main "SMART" curve in the figures.

```bash
python run_SMART.py    <model_id> <exp_id> <rd_seed_id>
python run_SMARTCV.py  <model_id> <exp_id> <rd_seed_id>     # supports exp_id in {0, 3}
```

These produce `SMART_result_*.pkl` and `SMARTCV_result_*.pkl` files under
`result/<model>/<exp>/`. The package default `gamma=2.0` matches the value used for
the paper's main figures.

## 6. HPC orchestration (optional)

The `submit_*_m<model_id>.sh` scripts are Slurm array submissions that fan out
`rd_seed_id = 0..99` automatically. They are kept as convenient examples; you can run
the same experiments serially on a laptop, or adapt them to a different scheduler.

Before submitting, edit the following placeholders for your cluster:

- `#SBATCH --account=YOUR_ACCOUNT` — replace `YOUR_ACCOUNT` with your Slurm account.
- `module load python/3.12` and `module load R/4.3` — adjust to match the module
  names on your cluster.
- `source "${VENV:-$HOME/SMART_experiments}/bin/activate"` — either place your
  Python virtual environment at `$HOME/SMART_experiments/` or `export VENV=/path/to/venv`
  before running `sbatch`.

A self-contained "hello world" replication on one seed, one model, one sub-experiment:

```bash
Rscript run_RRR.R   0 0 0
Rscript run_SRRR.R  0 0 0
Rscript run_RSSVD.R 0 0 0
Rscript run_SOFAR.R 0 0 0
python run_SMART.py   0 0 0
python run_SMARTCV.py 0 0 0
```

For the full 100-seed sweep, loop over `rd_seed_id` or submit the Slurm array scripts.

## 7. Figures

Once every cell in the `(model_id, exp_id, rd_seed_id)` grid has a result file,
assemble the panels with:

```bash
python visualize_simulation.py 0    # Model-I
python visualize_simulation.py 1    # Model-II
python visualize_simulation.py 2    # Model-III
```

Each call writes one PDF into `fig/simulation_<model>.pdf`. These are the 2x2 panels
shown in Section 5 of the paper; missing seeds are silently skipped, so you can start
plotting partial results early.

## 8. Expected runtime

All runs are embarrassingly parallel over `rd_seed_id`. Typical per-run cost on one CPU:

| Step | Model-I | Model-II | Model-III |
|---|---|---|---|
| One RRR/SRRR/RSSVD/SOFAR run | seconds | seconds | seconds |
| One `run_SMART.py` or `run_SMARTCV.py` run | ~1 min | ~3 min | ~10–20 min |

Plan ~1 CPU-day for the full Model-III SMARTCV sweep on exp1+exp4 (200 runs).
